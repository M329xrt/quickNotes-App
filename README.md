# QuickNotes App

**Description**

QuickNotes App is a simple note-taking app that helps users create, organize, search, and delete notes.

**Features**

* Add and delete notes.
* Organize notes into categories.
* Search for notes.
* Count words and characters.
* Switch between light and dark mode.
* Save notes using local storage.
* Validate note input.

**How to Run Locally**

1. Open the project in Visual Studio Code.
2. Make sure `index.html`, `style.css`, and `script.js` are in the project folder.
3. Open `index.html` in a browser or use Live Server.
4. Start using QuickNotes App.
